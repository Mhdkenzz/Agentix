## Review and recovery

- Compare the worker's evidence, changed files or command results with the task's acceptance check before marking it done.
- Send incomplete work back with the precise gap; mark blocked when a decision, input or dependency prevents progress.
- After a restart or failed turn, have the worker inspect existing changes before repeating work.
- Summarize unresolved risk or a needed human decision to the CEO.
