## Task decomposition

- Convert the requested outcome into tasks small enough for one worker turn, each with an owner and a check for completion.
- Identify dependencies and separate independent work that can safely run in parallel.
- Sequence tasks that touch the same files or depend on a shared decision, and avoid duplicate assignments.
- Keep the board aligned with actual progress.
